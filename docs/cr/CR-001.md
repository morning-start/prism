## 2. 影响域说明

- **不改库**：无 DB / 存储 / 序列化格式变更。
- **不重构**：不新增 Lucent IR 字段、枚举、事件或能力 ⇒ 不触发
  [`rules/lucent-ir-evolution.md`](rules/lucent-ir-evolution.md) 治理提案。
- **影响既有行为**（`affects_old_features: true`）：
  - 流式输出字节变化：重复 `finish_reason` 帧消失；Anthropic 目标的
    `message_delta.usage.output_tokens` 不再被第二条帧清零；usage 数值补齐输入侧；
    gemini→openai 的 usage 帧从 `[DONE]` 之后前移到之前。
  - 出站 openai 流式请求多一个标准字段 `stream_options.include_usage`
    （调用方自带值优先，不会被覆盖）。
  - 相关快照测试需同步更新，更新处需在验收时逐条解释。

## 4. 触发原文与归因纠正（provenance）

触发原文（逐字，用户转述其他项目反馈）见 §1 `req_original`。复核结论纠正了两处归因：

1. 「上游 SSE 不返回 usage」不成立 —— Anthropic / Gemini / Responses 的流式**始终**返回 usage；
   仅 OpenAI 需 `stream_options.include_usage`，而 Prism 从不请求它（D4）。
2. 「IR 转换把末帧消费掉了」不成立 —— OpenAI 源 usage 帧 decode→encode 逐字节保真（P5/P12）；
   真实机制是 D1 / D2 / D3。
