## 2. 影响域说明

- **不改库**：无 DB / 存储 / 序列化格式变更。
- **不重构**：不新增 Lucent IR 字段、枚举、事件或能力 ⇒ 不触发
  [`rules/lucent-ir-evolution.md`](rules/lucent-ir-evolution.md) 治理提案。
  （item 3 只在 `lux` 上增加读取既有 extension 载体 `ConversationMeta.extra` 的**访问器**，
  不改变 IR 结构。）
- **影响既有行为**（`affects_old_features: true`）：
  - Gemini 流式输出**新增首帧**（`message_start` / `response.created` / 带 id 的首个 chunk）；
  - 终止符改为**会话收尾发射**（`StreamConverter::finish()`），下游需按既有契约调用 `finish()`
    才能拿到尾部帧；同一事件组内不再出现"内容紧跟终止符"；
  - messages 编码器的 Usage/Finish 配对规则变化（正常 Anthropic 形态字节不变）；
  - 截断流新增合成的 `content_block_stop`（整缓冲与逐帧同构）。
