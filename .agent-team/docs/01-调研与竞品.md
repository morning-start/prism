# 01-调研与竞品

> PM 主导维护。调研结论按证据决策，标注来源与日期。上轮（2026-10-24）仅有框架，

## 1. 定位（单一事实源，与 00-需求池 §0.1 一致）

Prism = LLM 协议转换引擎（MoonBit 实现）：任意厂商 JSON/SSE → 中立 Lucent IR → 目标
协议；无两两转换器。两类消费者：Agent 框架 SDK（单 provider）、中转 middleware
（N provider：审计/改写/路由/过滤），外加 WASM 宿主。

## 2. 竞品与替代方案

| 方案 | 模式 | 与 Prism 差异 | 调研状态 |
|---|---|---|---|
| Vercel AI SDK | 应用层多 provider 抽象 | 偏 SDK 场景（单 provider 消费），非中转 IR | 待深调：其 provider 注册模型 vs Prism 静态表 + T6 动态注册 |
| LiteLLM | Python proxy 网关 | 偏 middleware；Prism 差异化在 MoonBit/WASM 可嵌入 + 显式保真度诊断 | 待深调：其转换降级是否有显式诊断 vs 静默丢弃 —— 直接验证 Prism「绝不静默丢弃」的差异化价值 |
| Portkey / Helicone | 托管网关（SaaS） | SaaS 形态；Prism 可自托管、可审计 | 低优先（形态不同，非直接竞品） |
| 各厂商官方 SDK | 直连单协议 | 不解决跨协议 | 无需深调 |
| LangChain JS/Python 的 model abstraction | 框架内抽象层 | 抽象埋在框架里，不可独立复用 | 待评估其字段覆盖面 |

- **重点（已交付）**：4 协议互转、流式转换、保真度矩阵（Exact/Degraded/Unsupported/
  Invalid）、显式诊断、官方 schema 校验 oracle（2026-10-24 上线）
