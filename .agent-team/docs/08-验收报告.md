#### 3. QA 补充实验（13 项，TL 测试未覆盖的边界；脚本 temp/ 下已完成删除）

wrapper 状态机与防线（全过）：N1 `convertResponse` 语义正确+零诊断；N2 `convertStreamEvent` 单事件产出帧；N4 `finish()` 二次调用返回 `[]`（幂等）；N5 `free()` 后 `finish()` 抛 SESSION_STATE；N6 fake 导出喂畸形信封 → ENVELOPE_INVALID（完整性防线真红）；N7 freed 后 `finished()` 短路 true 不触 wasm；N8 错误信封 diagnostics 透出；并发探针：双 session 交错 feed 输出互不串扰、free 后 slot 复用无残留。

跨层发现（引出 P1-1）：N3 组实验 3/5 失败——「可解析但结构错误」的请求文档（顶层数组 `[1,2,3]`、顶层 `42`、`messages:42`、`messages:null`）**不抛错**，静默降级为空 IR 请求且无 Invalid 诊断（探针实证 4 端 decode 皆然，仅 messages 目标附带一条无关的 max_tokens Degraded）；而 JSON 语法层畸形（空串、非法 JSON）正确抛 CONVERSION_ERROR，response 通路对 `42`/`[1]` 显式报错（`response has no choices`）。Invalid 诊断机制本身在 encode 端（tool args 非法回退）与 responses stream decode 端已启用——故这是 **request decode 端的不对称宽大**，非机制缺失。

#### 4. 缺陷清单

**P0：无。**

**P1-1（core 层，wrapper 无责）｜request decode 对结构畸形文档静默降级，0 诊断** —— 触发 07 分级定义「保真度降级未给诊断（违反『绝不静默丢弃』）」；违反 04 契约「Unsupported capabilities MUST fail explicitly」。中间件场景实害：上游发错型 body（如网关把 body 换成了数组）会被转成空请求发往 Anthropic 并附带默认 max_tokens=4096，错误被静默放大到下游厂商侧。**归属：`src/provider/*/request_decode`（core），非本次 TASK-4 交付物；wrapper 如实透传。** 处置三选一：① core 修复（结构畸形 → Invalid/CONVERSION_ERROR）；② fidelity-matrix 登记书面豁免（对齐 TD-001 缓解策略先例）+ 补 decode 负向测试钉住行为；③ 本里程碑书面豁免 + M2 随 B-001~004 治理一并偿还。**发布前必须清零（修复或书面豁免）**——QA 有阻塞权，但鉴于其不在 TASK-4 范围且 TC-1/TC-3 主线不受影响，作有条件通过处理。

**P2-1（wrapper 文档）｜产物路径漂移** —— README「Install」与 USAGE §4.1 均称 `moon build --target wasm-gc` 产出 `_build/wasm-gc/release/.../main.wasm`；实证本机构建后仅存在 `debug/` 产物（moon 默认 debug，release 需 `--release`）。TL 的 README 开发节用词「artifact in place」本已正确。整改：改为 debug 路径或注明 `--release`。

**P2-2（测试覆盖）｜4 项公开契约无直接断言** —— `convertResponse`/`convertStreamEvent`/`finish()` 幂等/`free()` 后 `finish()` 在 TL 的 12 项测试中无直接测试（QA 以临时实验 N1/N2/N4/N5 验证当前实现全部正确）。整改：将 4 个断言收编进 `wrappers/ts/test/`（可参照 QA temp 脚本，已删可重写）；ACC-001 第 1 条的 `src/sdk` 直连对拍可在收编时一并评估（CI 成本 vs 收益，QA 不强制）。

**P2-3（测试卫生）｜STREAM_FRAMES 拼接含逗号连接符** —— `test/prism-client.test.mjs:120` 用 `数组.map().join` 缺省分隔符 + `+'data: [DONE]\n\n'` 产生 `...\n\n,` 前缀帧；碰巧被解析器容忍且不影响断言语义。整改：`.join('')` 显式空分隔符。
